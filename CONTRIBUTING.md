# Contributing

Thanks for your interest. P2P Chat is a security tool, so it follows a strict rule:

**Pull requests from outside contributors are not merged.** Even a careful review can miss a
well-hidden change, and the classic attack on open-source security software is a helpful
contributor who builds trust over months before slipping something in. Instead:

- **Bugs, ideas, questions:** open an issue. Describe what you saw, on which OS and version.
- **A fix or a feature you'd like:** describe it in an issue (code snippets welcome as an
  illustration). If it's accepted, the maintainer writes and reviews the change.
- **A security problem:** never in a public issue. See [SECURITY.md](SECURITY.md).

Builds of pull requests from outside contributors only run after the maintainer approves them.
